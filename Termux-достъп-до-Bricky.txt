TERMUX ДОСТЪП ДО BRICKY СЪРВЪРА
================================

Използва се SSH, не SSL.


1. ИНСТАЛИРАНЕ НА SSH В TERMUX
------------------------------

pkg update
pkg install openssh


2. СВЪРЗВАНЕ СЪС СЪРВЪРА
------------------------

ssh root@94.72.143.22

При първото свързване напиши:

yes

След това въведи root паролата.
Паролата няма да се вижда на екрана, докато я пишеш.


3. ОТВАРЯНЕ НА LIVE ПРОЕКТА
---------------------------

cd /var/www/Bricky-sprint3-release
pwd
git status


4. ПРОВЕРКА НА ПРОЦЕСИТЕ
------------------------

pm2 status
pm2 show bricky-backend


5. ПРОВЕРКА ДАЛИ САЙТЪТ РАБОТИ
------------------------------

curl -s https://bricky.bg/api/health/ready

Нормалният резултат трябва да съдържа:

"status":"ok"
"database":"ok"
"storage":"ok"


6. ПРЕГЛЕД НА BACKEND ЛОГОВЕТЕ
------------------------------

pm2 logs bricky-backend --lines 100

За излизане от логовете натисни:

Ctrl+C


7. ПРИБЛИЗИТЕЛЕН БРОЙ ПОСЕТИТЕЛИ ДНЕС
-------------------------------------

awk -v d="$(date -u +%d/%b/%Y)" '$4 ~ d {print $1}' /var/log/nginx/access.log | sort -u | wc -l

Забележка: това брои уникални IP адреси. Един човек може да използва
няколко IP адреса, а няколко души могат да споделят един адрес.


8. НАЙ-АКТИВНИ IP АДРЕСИ ДНЕС
-----------------------------

awk -v d="$(date -u +%d/%b/%Y)" '$4 ~ d {print $1}' /var/log/nginx/access.log | sort | uniq -c | sort -nr | head -20


9. ПРОВЕРКА ОТКЪДЕ Е ДАДЕН IP АДРЕС
-----------------------------------

curl -s "https://ipwho.is/ВЪВЕДИ_IP_ТУК"

Пример:

curl -s "https://ipwho.is/212.5.142.98"


10. ПРОВЕРКА НА NGINX
---------------------

nginx -t
systemctl status nginx --no-pager


11. ПРОВЕРКА НА СВОБОДНОТО МЯСТО
--------------------------------

df -h


12. ИЗЛИЗАНЕ ОТ СЪРВЪРА
-----------------------

exit


ВАЖНО ЗА СИГУРНОСТТА
====================

Не записвай root паролата директно в SSH команда, скрипт или текстов
файл в телефона. Не изпращай паролата в чат или снимка на екрана.
